# 24 小时时钟

纯前端 24 小时制时钟：**一个 HTML 文件、零依赖、零构建**，双击即可运行。

## 特点

- **真正的 24 小时表盘**：时针一天只转一圈，`0` 在正上方、`12` 在正下方
- **昼夜色带**：表盘外圈 24 个扇区按时间着色 —— 白天暖黄（6–17 点）、黄昏橙（18–21 点）、夜间蓝
- **日进度弧**：最外圈橙色弧线与光点，绕满一圈正好是一整天
- **表盘日历窗**（v2.0）：表盘正下方开一扇弧形窗口，直接显示今天的日期数字，指针扫不到
- **可翻页月历**（v2.0）：右侧面板带完整月历，`‹` `›` 切换月份、高亮今天、"回到今天"一键返回
- **年度进度**（v2.0）：当前日期在全年的进度百分比 + 进度条 + "第 N 天 / 共 M 天 · 距年底还有 K 天"
- **平滑秒针**：基于 `requestAnimationFrame` 连续扫动，不是逐秒跳动
- **数字读数**：24 小时制 `HH:MM:SS` + 日期星期，浏览器标签标题同步显示
- 刻度每 15 分钟一短线、每小时一长线，24 个数字全部标注

## 使用

```bash
open 24h-clock.html      # 当前版本 v2.0
open 24h-clock-v1.html   # v1.0 存档
```

或者直接把文件拖进浏览器。无需联网、无需安装任何东西。

## 实现说明

- 原生 SVG + 原生 JS，无框架、无第三方库、无外部字体
- 表盘的静态部分（24 个色带扇区、96 条刻度、24 个数字、日历窗）在加载时生成一次；此后每帧只更新三根指针的 `transform` 与日进度弧，秒级再更新读数与统计
- 月历用固定 42 格 + `Date` 自动归一化跨月日期；跨天时只刷新"今天"高亮，不打断用户正在翻看的月份
- 年度天数统计用 `Math.round` 抵消夏令时造成的 ±1 小时偏移
- 表盘尺寸与字号用 `vmin` + `clamp()` 自适应，小窗口下不会溢出
